## smart-image-studio

画像をアップロードし、処理パイプラインを組み立て、元画像と加工後画像を比較できる Web アプリです。

- **Frontend**: React / TypeScript / Vite / Tailwind CSS / Feature-Sliced Design
- **Backend**: Python / FastAPI / PostgreSQL / OpenCV / RapidOCR / MobileNet-SSD

詳細は [smart-image-studio/README.md](./smart-image-studio/README.md) を参照してください。
