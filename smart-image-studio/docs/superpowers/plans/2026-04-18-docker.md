# Docker 対応 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `docker compose up --build` 一発で frontend (Vite) と backend (FastAPI) が両方ホットリロード付きで起動できるようにする。

**Architecture:** backend/frontend それぞれに専用 Dockerfile と .dockerignore を用意し、`docker-compose.yml` でまとめる。ソースはボリュームマウントでホットリロード、`.venv` と `node_modules` は named volume で永続化する。backend の healthcheck を frontend の `depends_on` に連携させ起動順を制御する。

**Tech Stack:** Docker Compose, python:3.13-slim, node:22-alpine, Poetry, Vite

```dockerfile
FROM python:3.13-slim

ENV POETRY_VIRTUALENVS_IN_PROJECT=true

RUN pip install poetry

WORKDIR /app

COPY pyproject.toml poetry.lock poetry.toml ./
RUN poetry install --no-root

COPY . .

CMD ["poetry", "run", "uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000", "--reload"]
```

### Task 3: `docker-compose.yml` を作成する

**Files:**
- Create: `smart-image-studio/docker-compose.yml`

- [ ] **Step 1: `docker-compose.yml` を作成する**

`smart-image-studio/docker-compose.yml` を以下の内容で作成する：

```yaml
services:
  backend:
    build: ./backend
    ports:
      - "8000:8000"
    volumes:
      - ./backend:/app
      - backend_venv:/app/.venv
    env_file:
      - ./backend/.env
    healthcheck:
      test: ["CMD", "python", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:8000/health', timeout=2)"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 10s

  frontend:
    build: ./frontend
    ports:
      - "5173:5173"
    volumes:
      - ./frontend:/app
      - frontend_node_modules:/app/node_modules
    env_file:
      - ./frontend/.env
    depends_on:
      backend:
        condition: service_healthy

volumes:
  backend_venv:
  frontend_node_modules:
```

````markdown
## Docker での起動（推奨）

### 前準備（初回のみ）

```bash
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```

### 起動

```bash
cd smart-image-studio
docker compose up --build  # 初回 or Dockerfile 変更時
docker compose up          # 通常
```

### 停止

```bash
docker compose down          # 停止（named volume は保持）
docker compose down -v       # named volume も含めて完全削除
```

起動後:

- frontend: `http://localhost:5173`
- backend: `http://localhost:8000`
- health check: `http://localhost:8000/health`
````
